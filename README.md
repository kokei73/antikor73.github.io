# Интерактивный 3D-персонаж (Unity Project)

Этот проект представляет собой модульную систему управления 3D-персонажем для Unity, включающую систему динамического переодевания и текстовые команды (на русском и английском) для анимаций и смены одежды.

## Структура папок
- `Assets/Scripts/`: C# скрипты (`CharacterWardrobe`, `CommandProcessor`, `CharacterAnimationController`, `ChatUI`).
- `Assets/Models/`: Поместите сюда вашу 3D модель (.glb, .fbx).
- `Assets/Materials/`: PBR материалы.

## Инструкция по импорту модели из Blender / Meshy
1. **Импорт**: Перетащите вашу .glb или .fbx модель в папку `Assets/Models/`. Убедитесь, что модель имеет Rig типа "Humanoid" во вкладке Rig настроек импорта.
2. **Модульность**: В Blender персонаж должен быть разбит на отдельные меши:
   - Base Body (тело)
   - Top (топ/футболка)
   - Bottom (джинсы/юбка)
   - Bra (лифчик)
   - Panties (трусики)
   - Dress (платье)
3. **Настройка префаба**:
   - Вытащите модель на сцену.
   - Добавьте на неё компоненты: `CharacterWardrobe`, `CommandProcessor`, `CharacterAnimationController` и `Animator`.
   - В компоненте `CharacterWardrobe` заполните массивы `Wardrobe Items` ссылками на соответствующие SkinnedMeshRenderers (например, `itemName` = "Top", `category` = "Top").

## Настройка материалов (Alpha Clipping)
Для предотвращения clipping (прохождения меша тела сквозь одежду) рекомендуется использовать Alpha Clipping:
1. Создайте материал для тела. Выберите шейдер `Standard` или `URP/Lit` (если используете URP).
2. Измените `Rendering Mode` на `Cutout`.
3. Используйте текстуру с маской альфа-канала, где области тела под одеждой черные (прозрачные), а открытые участки - белые (непрозрачные).
4. Альтернативный метод, реализованный в скрипте: простое включение/выключение мешей (одежды) работает надежно, если одежда полностью заменяет часть тела.

## Быстрый старт (Quick Start)
1. Откройте сцену с персонажем и запустите Play Mode.
2. В интерфейсе чата введите следующие команды для проверки:

   **Одежда и раздевание:**
   1. `"сними всё"` или `"разденься полностью"` — снимает всю одежду.
   2. `"останься в белье"` или `"надень только бельё"` — оставляет только трусики и лифчик.
   3. `"оденься"` или `"надень всё"` — возвращает базовую одежду (джинсы, футболка).
   4. `"сними только топ"` — снимает только верхнюю часть одежды.
   5. `"надень красное платье"` — надевает платье, автоматически снимая топ и джинсы.
   6. `"сними бельё"` — снимает лифчик и трусики (если они были надеты).

   **Анимации:**
   7. `"потанцуй"` — запускает анимацию танца.
   8. `"наклонись вперёд"` — запускает анимацию наклона.
   9. `"сядь на колени"` — персонаж садится на колени.
   10. `"ляг на спину"` — персонаж ложится.
   11. `"повернись спиной"` — персонаж поворачивается к камере спиной.
   12. `"помахай рукой"` — персонаж машет рукой в знак приветствия.

## Настройка Animator Controller
Для работы скрипта `CharacterAnimationController` вам необходимо настроить Animator.
1. Создайте `Animator Controller` в `Assets/` и назначьте его компоненту `Animator` персонажа.
2. Во вкладке **Parameters** создайте следующие параметры типа `Trigger` (названия должны совпадать точно с учетом регистра):
   - `Dance`
   - `Turn`
   - `BendOver`
   - `LieDown`
   - `Sit`
   - `Idle`
   - `Wave`
3. Создайте состояния (States) для анимаций и назначьте им соответствующие Animation Clips (например, скачанные из Mixamo).
4. Создайте переходы (Transitions) из состояния **"Any State"** к соответствующим анимациям.
5. В условиях (Conditions) каждого перехода выберите соответствующий триггер (например, для анимации танца выберите условие `Dance`). Убедитесь, что галочка "Can Transition To Self" снята, чтобы анимация не перезапускалась бесконечно при активном триггере.

## Настройка Kawaii Physics (PhysicsHelper)
В проекте предусмотрена автоматическая настройка реалистичной физики груди, ягодиц и волос через скрипт `PhysicsHelper`.

**Шаг 1. Импорт ассета**
Скачайте и импортируйте бесплатный ассет `Kawaii Physics` с GitHub. Без него скрипт не выдаст ошибку, но физика работать не будет.

**Шаг 2. Поиск костей в иерархии (Hierarchy)**
Разверните иерархию вашей модели (Armature / Hips / Spine...).
- **Грудь:** Обычно кости называются `Breast_L`, `Breast_R` или `DEF-breast.L`. Они находятся дочерними к верхней части позвоночника (`Spine2` или `Chest`).
- **Ягодицы:** Обычно называются `Butt_L`, `Butt_R` или `Glute_L`. Они являются дочерними к тазу (`Hips` или `Pelvis`).
- **Волосы:** Найдите кости `Hair_Root` или `Ponytail` внутри кости головы (`Head`).

**Шаг 3. Назначение костей**
1. Выберите персонажа.
2. В компоненте `CharacterWardrobe` (раздел **Physics**) назначьте:
   - `Breast Left` / `Breast Right`
   - `Butt Left` / `Butt Right`
   - `Hair Root`
3. Убедитесь, что в поле `Physics Helper` перетащен сам скрипт `PhysicsHelper` (он должен висеть на том же GameObject или на пустом объекте).

**Шаг 4. Настройка параметров (Physics Profiles)**
В компоненте `PhysicsHelper` вы можете настроить параметры в инспекторе:
- **Move Radius** (Радиус движения): Ограничивает, как далеко кость может уйти от исходного положения.
- **Stiffness** (Жесткость): Скорость возврата кости на место.
- **Gravity Power** (Гравитация): Сила, тянущая кость вниз.
- **Drag Force** (Сопротивление/Демпфирование): Делает движение более плавным, гасит колебания.

*Рекомендуемые значения:*
- **Грудь (Breast):** Move Radius = 0.05, Stiffness = 0.8, Gravity Power = 0.2, Drag Force = 0.1
- **Ягодицы (Butt):** Move Radius = 0.07, Stiffness = 0.9, Gravity Power = 0.2, Drag Force = 0.1
- **Волосы (Hair):** Move Radius = 0.1, Stiffness = 0.5, Gravity Power = 0.1, Drag Force = 0.2

## Управление камерой (CameraController)
В проекте добавлен скрипт `CameraController`, который позволяет удобно осматривать персонажа.
1. Повесьте скрипт `CameraController.cs` на вашу `Main Camera`.
2. В инспекторе перетащите персонажа в поле **Target**.
3. Настройте **Target Offset** (смещение по высоте), чтобы камера фокусировалась на уровне груди/лица (например, `Y = 1.2`).
4. **Управление в игре:**
   - Зажмите **правую кнопку мыши (ПКМ)** и двигайте мышью для вращения камеры вокруг персонажа.
   - Используйте **колёсико мыши** для плавного приближения и отдаления (Zoom).

## Чек-лист после импорта модели (Post-Import Checklist)
Чтобы убедиться, что всё настроено верно, пройдитесь по этому списку:
- [ ] Риг модели установлен как **Humanoid** (вкладка Rig настроек импорта).
- [ ] Материалы настроены на **Cutout / Alpha Clipping** для корректного отображения тела под одеждой.
- [ ] Скрипты `CharacterWardrobe`, `CommandProcessor` и `CharacterAnimationController` добавлены на корень персонажа.
- [ ] Массивы одежды (`Wardrobe Items`) заполнены ссылками на соответствующие SkinnedMeshRenderer (топ, джинсы, лифчик, трусики).
- [ ] Скрипт `PhysicsHelper` висит на персонаже, кости (грудь, ягодицы, волосы) перетащены в его поля.
- [ ] Поле `Physics Helper` в компоненте `CharacterWardrobe` заполнено.
- [ ] Animator Controller создан, добавлены триггеры (`Dance`, `BendOver`, и т.д.), настроены переходы из `Any State`.
- [ ] `Main Camera` имеет скрипт `CameraController` и смотрит на персонажа.
- [ ] Скрипт `ChatUI` привязан к UI-элементам и ссылается на `CommandProcessor`.

## Рекомендуемые ассеты
Для достижения наилучшего результата и реалистичности рекомендуется использовать:
1. **Kawaii Physics** (бесплатно, GitHub) — для создания реалистичного jiggle эффекта (интеграция уже встроена в `PhysicsHelper`).
2. **TextMeshPro** — для более качественного рендера текста в UI чата (замените стандартные `Text` компоненты на `TextMeshProUGUI`).
3. **Mixamo Animations** — бесплатная библиотека качественных анимаций, отлично подходящих под параметры триггеров в `Animator Controller`.

## Настройка UI
1. Создайте UI Canvas (GameObject -> UI -> Canvas).
2. Добавьте `InputField` для ввода текста и несколько кнопок (`Button`).
3. Создайте пустой GameObject и добавьте на него скрипт `ChatUI`.
4. В инспекторе свяжите UI элементы с соответствующими полями в `ChatUI` и перетащите персонажа со скриптом `CommandProcessor` в поле `Character Reference`.
